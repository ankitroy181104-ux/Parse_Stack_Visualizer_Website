02 / THE CONCEPTS

Three ideas. One parser.

Understand what the visualizer is doing at every step.

01
▤

The parsing stack

A last-in, first-out structure that tracks grammar symbols still to be processed. The top symbol is examined at each step.

LIFO · PUSH · POP
02
⤷

Production rules

The parser expands a non-terminal using the next input token, called the lookahead. Right-hand-side symbols are pushed in reverse order.

LL(1) · LOOKAHEAD
03
⑂

The parse tree

A tree showing how grammar productions derive the expression. Non-terminals branch into their production symbols.

ROOT · CHILDREN · LEAVES
03 / THE FORMAL GRAMMAR

Built on a simple
expression grammar.

This grammar is suitable for LL(1) predictive parsing. It separates expressions, terms, and factors to encode operator precedence.

×Precedence is built inMultiplication binds tighter than addition; parentheses can override it.

F → (E) | i
